SynHub

Unofficial, from-scratch client for Synology NAS — not affiliated with or endorsed by Synology Inc.
Current Linux package version: 0.2.8 · all downloads on GitHub Releases

Debian / Ubuntu

curl -fsSL https://openviewmobile.github.io/synhub/keys/synhub-archive-keyring.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/synhub.gpg
echo "deb [signed-by=/usr/share/keyrings/synhub.gpg] https://openviewmobile.github.io/synhub/repo/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/synhub.list
sudo apt update && sudo apt install synhub

Fedora / RHEL / openSUSE

sudo curl -fsSL https://openviewmobile.github.io/synhub/repo/rpm/synhub.repo \
  -o /etc/yum.repos.d/synhub.repo
sudo dnf install synhub

Both repositories are GPG-signed — package and index (repo_gpgcheck=1).

The repository is x86_64 only: Flutter does not publish a Linux arm64 SDK, so no arm64 package can be built. On arm64 use the Android build or build from source on an x64 machine.

Verify before you install

curl -fsSLO https://github.com/openviewmobile/synhub/releases/latest/download/SHA256SUMS.txt
curl -fsSLO https://github.com/openviewmobile/synhub/releases/latest/download/SHA256SUMS.txt.asc
gpg --keyserver hkps://keys.openpgp.org --recv-keys 9E85497E64A128A1427CD5F8AEF0C14A16617FE8
gpg --verify SHA256SUMS.txt.asc SHA256SUMS.txt && sha256sum -c SHA256SUMS.txt

Other platforms

Android (arm64-v8a), iOS (unsigned), macOS (ad-hoc), Windows (x64) and Web builds ship on the Releases page; every release is re-verified by the verify-release workflow with the published key.

macOS and Windows builds are not signed with a commercial certificate (none is purchased, deliberately): on macOS right-click the app → Open, or run xattr -dr com.apple.quarantine /Applications/SynHub.app; on Windows choose More info → Run anyway at the SmartScreen prompt.
